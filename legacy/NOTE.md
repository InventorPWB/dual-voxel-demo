# Legacy: hybrid blocks + smooth terrain

The first design of this demo: exact cube blocks and a smooth terrain field in one grid, meshed separately and reconciled by the mesher. Shelved in favour of the everything-is-voxels design in `/src` (see the root README for why).

Still runnable: with `npm run dev` going, open http://localhost:5173/legacy/ . Its tests live in `legacy/test` and are excluded from `npm test`.
